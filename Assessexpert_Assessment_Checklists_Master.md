# assessexpert — Master Assessment Evaluation Checklists
## Practical Assessment Rubric Library — All Roles

> **Document Version:** 1.0  
> **Classification:** INTERNAL — Proctor & Admin Use Only  
> **Purpose:** Standard evaluation checklists for practical assessment scoring across all supported job roles. Each checklist is designed to be loaded into the Admin Portal as a structured rubric and used by proctors during post-session evaluation.  
> **Scoring Scale:** 1 = Poor | 2 = Below Average | 3 = Average | 4 = Good | 5 = Excellent  
> **Report Format:** Score × Weightage = Final Score. Section totals feed into the overall weighted percentage.  
> **Pass Threshold (default):** 60% overall; configurable per assessment by HR.

---

## How to Use This Document

Each checklist below follows a **standardised structure**:

```
Assessment Name
├── Section A — [Primary Skill Domain]     (weighted %)
├── Section B — [Secondary Skill Domain]   (weighted %)
├── Section C — [Tertiary Skill Domain]    (weighted %)
├── Section D — [Supporting Competency]    (weighted %)
└── Section E — Workflow & Professionalism (fixed across all roles)
```

Each activity item includes:
- **Sr. No.** — Sequence number within section
- **Activity** — The observable behaviour or deliverable being evaluated
- **Proctor Guidance** — What to look for / how to score
- **Max Score** — Maximum raw score (scale 1–5)
- **Weightage** — Multiplier reflecting importance of activity
- **Max Final Score** — Score × Weightage ceiling

## Appendix C — Proctor Scoring Instructions

### During Practical Assessment (60-minute session)

1. Watch candidate's **screen share** via the Proctor Control Panel
2. Observe **working methodology** — not just the output file
3. Take **timestamped notes** on the session event log for:
   - Any checklist item where score is 1 or 2
   - Any notable positive or negative technique observed
   - Any deviation from task brief

### Post-Session Evaluation Workflow

```
Session Submitted
      ↓
Open Post-Session Review Panel
      ↓
View Screen Recording (dual-pane: webcam + screen)
      ↓
Open Submission File(s)
      ↓
Score Each Checklist Item:
  - Review recording for process-based items (speed, shortcuts, methodology)
  - Review submitted files for output-based items (accuracy, completeness)
  - Enter Score (1–5) for each item
  - Add proctor comment for any score ≤ 3
      ↓
Review AI Draft Report — modify narrative where needed
      ↓
Publish Report → HR Dashboard
```
