### Step 1: Enable 2-Factor Authentication (If Not Already)

1. Go to: https://myaccount.google.com/security
2. Sign in with: `theassessexpert@gmail.com`
3. Find "2-Step Verification"
4. If not enabled, click "Get Started" and follow the steps
5. **You MUST have 2FA enabled to create App Passwords**

### Step 2: Generate App Password

1. Go to: https://myaccount.google.com/apppasswords
2. Sign in with: `theassessexpert@gmail.com`
3. You'll see "App passwords" page
4. Click "Select app" → Choose "Mail"
5. Click "Select device" → Choose "Windows Computer"
6. Click "Generate"
7. Google will show a 16-character password like: `abcd efgh ijkl mnop`

### Step 3: Copy the App Password

**IMPORTANT:** Copy the password WITHOUT spaces!

Example shown: `abcd efgh ijkl mnop`
Copy as: `abcdefghijklmnop`

Open: `d:\Assess Expert New\assessexpert\backend\.env`

Find this line:
```env

```

Replace with your App Password (no spaces):

## 🎯 Quick Reference

### What is a Gmail App Password?

- **NOT** your regular Gmail password
- **16-character** code generated by Google
- **Specific** to one app/device
- **Secure** - can be revoked anytime
- **Required** when using 2FA with third-party apps

### Format Examples

❌ **WRONG:**
```env
SMTP_PASS=Assess@Expert@2026          # Regular password
SMTP_PASS=your-gmail-app-password     # Placeholder
SMTP_PASS=abcd efgh ijkl mnop         # With spaces
```

✅ **CORRECT:**
```env
SMTP_PASS=abcdefghijklmnop            # 16 chars, no spaces
SMTP_PASS=xyzw1234abcd5678            # Another example
```

## 🔧 Troubleshooting

### Issue: "App passwords" option not showing

**Cause:** 2-Factor Authentication not enabled

**Solution:**
1. Go to: https://myaccount.google.com/security
2. Enable "2-Step Verification"
3. Wait 5 minutes
4. Try accessing App Passwords again

### Issue: "This setting is hidden"

**Cause:** Using Google Workspace account with admin restrictions

**Solution:**
- Contact your Google Workspace admin
- Or use a personal Gmail account instead

### Issue: Still getting "Invalid login" after setting App Password

**Checklist:**
- [ ] Copied password without spaces
- [ ] Used the App Password, not regular password
- [ ] Saved .env file after editing
- [ ] Restarted backend server
- [ ] SMTP_USER matches the Gmail account that generated the App Password

## 🔐 Security Notes

### DO:
- ✅ Keep App Password in .env file only
- ✅ Add .env to .gitignore (already done)
- ✅ Generate separate App Passwords for dev/prod
- ✅ Revoke App Passwords you're not using

### DON'T:
- ❌ Share App Password in chat/email
- ❌ Commit App Password to Git
- ❌ Use regular Gmail password in SMTP_PASS
- ❌ Reuse App Passwords across projects

### Revoke App Password (If Compromised)

1. Go to: https://myaccount.google.com/apppasswords
2. Find the App Password you created
3. Click "Remove"
4. Generate a new one
