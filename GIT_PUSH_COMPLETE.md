## 👥 For Team Members

When team members clone/pull the repository, they need to:

1. **Pull latest changes:**
   ```bash
   git pull origin main
   ```

2. **Install dependencies:**
   ```bash
   cd backend
   npm install
   ```

3. **Configure .env:**
   - Copy `.env` template or create new one
   - Generate JWT secrets: `npm run generate:secrets`
   - Set SMTP credentials (Gmail App Password)

4. **Run diagnostics:**
   ```bash
   npm run diagnostics
   ```

5. **Start backend:**
   ```bash
   npm run start:dev
   ```
